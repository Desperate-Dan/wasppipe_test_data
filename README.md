# WaSPPipe Test Data
This repo contains some example fastq data generated using Nanopore sequencing following the WaSPP protocols. It is to be used to test the consistency of results from the [WaSPPipe pipeline](https://github.com/Desperate-Dan/WaSPPipe).

The datasets may be updated over time to incorporate other aspects of pipeline we wish to test, but all example datasets will remain in this repo. Each example dataset will also include an expected output using a given version of the pipeline. During the initialisation of this repository [v1.2.1](https://github.com/Desperate-Dan/WaSPPipe/releases/tag/v1.2.1) is the latest version of WaSPPipe.

## Usage
To use the data within this repo first clone it using:
```
git clone https://github.com/Desperate-Dan/wasppipe_test_data.git
```
Then give the `fastq_pass` folder within the test data set of your choice as the input to WaSPPipe.

## Disclaimer
Please note this data set was generated by the [WaSPP consortium](https://www.waspp.org/) as part of their research project and is solely intended to be used as part of the pipeline testing for that project. These data do not represent real detections of the viruses contained within the reads!
